# 命中反馈与 UI 改造记录

实施日期：2026-09-13。工程：ThirdPerson，UE 5.8.2。保留原有未提交的动画、角色蓝图、教程、输入和连击修改；本轮不修改战斗伤害、动画特效、教程往返与下落攻击的规则。

## 实际修改顺序

1. 检查当前工作树和战斗结算路径。在两处近战结算后发出 `OnMeleeHitResolved` 原生事件，主角挂载独立 `HitFeedbackComponent`；没有向敌人、投射物或动画通知加入时间控制。
2. 在 Boss 的 Combat 决策中加入对峙选择和计时，沿用寻路、朝向、场地边界和原状态机优先级。
3. 为 `TreasureChestActor` 增加关闭／开启网格体和统一外观刷新，不修改掉落数量及开启事件。
4. 新建独立主菜单运行类及保存策略校验，增加跨地图会话缓存重置入口。
5. 新建属性只读快照与纯展示 Actor。原背包只修改窗口内部布局，HUD、提示、升级和胜负控件留在原位置。
6. 用户确认 ThirdPerson 已保存并关闭后，使用局部编辑工具保存新的菜单 WBP、菜单地图、肖像材质，并修改 `WBP_Inventory`。未重建教程、Boss 场景或动画。
7. 首次 UMG 保存遇到新控件 GUID 注册问题，已修复创建流程并重新编译，保存检查为零错误。首轮截图发现肖像材质采样类型不匹配、菜单缺少实例化植被及按钮换行，已补齐实例化树木／石路、禁止按钮标签换行，并明确浮点 RenderTarget 的线性采样设置，修复后重新截图验收。
8. 最后一轮逐图检查发现超宽菜单背景有摄像机 16:9 限制造成的黑边，已解除菜单镜头比例限制。肖像 Image 增加 ScaleBox 等比适配，避免方形 RenderTarget 被拉伸；镜头略偏移以留出剑尖空间。

## 关键规则

### 命中顿挫

- 默认持续 0.0333333 秒真实时间，世界倍率为进入前的 0.1 倍。使用 CoreTicker 和平台实时时钟，不使用受慢动作影响的世界计时器。
- 仅本地主角持近战武器、实际伤害大于零且未格挡／弹反时触发，含击杀；同 action serial 和命中组仅一次，多目标不叠加或延长。
- 结束、暂停、死亡或 EndPlay 清理。只有当前倍率仍等于本组件设置值时才恢复旧倍率，避免覆盖后来的时间控制。

### Boss 对峙

- 默认 30%，0.8–1.4 秒，两次开始至少相隔 5 秒；单轮决策仅抽一次，结束后优先尝试攻击。
- 面朝玩家侧移，在约 260–420 cm 距离活动；小于 180、大于 600、失去视线或状态优先级变化时退出。连续两次即时寻路失败退出，首次失败换方向。
- 仍由原技能合法性、破韧／阶段状态、场地边界约束，不新增技能，不改变技能伤害或动画速率。

### 菜单与存档

- 开始、继续、退出三个按钮；鼠标、方向键及 Enter。重开确认用 Enter 确认、Esc 取消。
- 开始前校验教程地图；有存档时必须确认，再确认删除成功后清空会话缓存并进入教程。
- 无正式存档时禁用继续；损坏或地图失效时显示错误，不静默删除。旧检查点没有地图名时按原关卡兼容；只有正式角色／竞技场奖励而无检查点时进入教程，正式数据仍保留在存档中。
- `GameDefaultMap` 指向主菜单，保留用户 `EditorStartupMap` 设置及直接在战斗图 PIE 的习惯。主菜单 UI 目录加入 AlwaysCook，避免纯 C++ 路径引用的布局／材质在打包时遗漏。

### 属性与肖像

- 属性来自实际组件快照，不在 UMG 复制伤害公式。武器原始攻击力和当前有效基础伤害分列；后者含等级、永久倍率及 Buff，不含单招／目标减伤。收刀显示徒手；没有填写武器显示名时回退资产名。
- 两页共用角色展示，复制当前骨骼网格、材质、武器网格和挂接状态。只生成非 Pawn 的展示 Actor，不创建第二个战斗角色或 WeaponActor，不运行动画蓝图／攻击特效通知。
- 每次打开创建独立 512×512 浮点 RenderTarget，手动最多 30 Hz 捕获。属性页可见时最多 10 Hz 取快照；隐藏不刷新。关闭、死亡及换图销毁展示 Actor，不继续捕获。

## 验证边界

自动化的顿挫时间验证采用真实时钟加 30／60／120 Hz 采样，不等同于三种帧率完整手工游玩。命中手感、Boss 对峙节奏仍需你实际对战确认；本轮未进行打包版本测试，也未穷举磁盘拒绝写入、所有装备／Buff 组合和每一处边界的长时间对战。已实现相关清理及错误处理，但不把未实测的情况标为通过。菜单未按示例制作新贴图，使用工程已有森林／遗迹实景；没有添加设置、标题或版本号。
