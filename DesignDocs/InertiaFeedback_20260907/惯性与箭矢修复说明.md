# 惯性、箭矢朝向与冲刺收招修复

2026-09-07 · ThirdPerson / UE 5.8.2

## 本次调整

| 反馈 | 原因与修改 |
|---|---|
| 箭横着飞 | 模型长轴是本地 +Y，投射物沿 +X 前进。ArrowMesh 相对 Yaw 改为 -90°，X 偏移 -83.014 cm，使箭尖与扫掠碰撞球重合，箭尾留在后方。未改变发射速度、瞄准或伤害。 |
| 冲刺斩后摇长 | 原蒙太奇约 1.58 秒。保留原片段与 1×播放速度，伤害仍在 0.28–0.55 秒；0.76 秒开始 0.12 秒淡出，约 0.9 秒恢复操作。Dodge/Guard 取消从 0.75 提前至 0.62 秒。 |
| 空中左键停止前进 | 普通 Air01/02 原先提取根位移，把跳跃速度覆盖为零。派生片段现在关闭位移提取、保留 ForceRootLock；胶囊继续使用原生跳跃运动和重力。升龙与下砸的专用轨迹/提交配置未改变。 |
| 落地速度骤然为零 | 移除了落地和接触阶段的硬停止。0.12 秒接触阶段采用指数阻尼，持续保持水平位移，然后接回走/跑。静止落地、蹲入和连续跳跃仍保留原有处理。 |

`LandingContactTime=0.12`、`LandingInertiaDrag=4` 位于主角的 Movement / Transitions。新的移动组件只处理接触阻尼；碰撞、坡面和重力仍由 CharacterMovement 执行，没有用传送模拟惯性。

## 实测

- 原行为专项：空中攻击水平速度从 450 降到 0；落地第一帧为 0；箭轴与飞行方向点积为 0；冲刺斩 1.05 秒时仍占用动作通道。
- 修改后：空中普通攻击水平速度持续为 450 cm/s；落地第一帧约 441–442 cm/s，短暂接触末段约 280 cm/s，再恢复移动。
- 箭矢测试使用真实远程敌人的蒙太奇释放通知，逐帧核对箭尖方向和碰撞位置，防止仅把横飞改成倒着飞。
- Editor / Win64 Development 构建通过。NullRHI **35/35**，RHI **35/35**；新专项覆盖 5 场景 × 30/60/120 Hz，并保留原有空战、闪避、蹲入、弹反及 Boss 重开回归。
- 既有空战一致性断言没有放宽：三个时步的完整空战伤害均为 **100.00**。
